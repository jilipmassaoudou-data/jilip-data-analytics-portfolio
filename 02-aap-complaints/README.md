# Health Data Analysis

## Overview

This project analyzes fictional healthcare activity data using SQL, MySQL and Power BI.

The objective is to explore patient activity, consultations and health structures and transform raw data into clear analytical insights.

## Key questions

- How many patients are recorded?
- How many consultations were conducted?
- Which health structures are represented?
- What patterns can be identified in consultation activity?

## Tools

- MySQL
- SQL
- Power BI
- DAX
- Power Query

## Workflow

Data → SQL/MySQL → Data preparation → Power BI → Dashboard → Insights

## Skills demonstrated

- SQL querying
- Data cleaning and preparation
- Data modeling
- KPI creation
- DAX measures
- Data visualization
- Dashboard design
