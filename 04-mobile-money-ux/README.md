# UX Research & Data Analytics — Mobile Money Niger

## Overview

This project is an independent simulated UX research case study exploring user experience during mobile money transactions in Niger.

The study focuses on the difficulties users may encounter when completing a financial transaction through two channels:

- Mobile application
- Agent / counter

The objective is to identify potential friction points, compare user experiences and translate quantitative findings into UX recommendations.

## Research question

What are the main friction points experienced by users during a financial transaction, and how do these difficulties vary between mobile applications and agent-based transactions?

## Methodology

The project simulates a quantitative user research study with:

- 500 fictional respondents
- 8 regions of Niger
- Mobile application and agent/counter channels
- Transaction types including transfers, withdrawals, deposits and payments
- Structured questionnaire designed with XLSForm
- Simulated dataset prepared in Excel

The questionnaire was designed following a research workflow:

XLSForm → KoboToolbox/KoboCollect → Data export → Excel → Power BI → UX analysis → Recommendations

## Key research dimensions

The analysis explores:

- Ease of use
- Satisfaction
- Transaction time
- Trust
- Main problems encountered
- Abandonment and near-abandonment
- Intention to reuse
- Recommendation intention
- User improvement suggestions

## Dashboard

The Power BI dashboard is organized into three analytical perspectives:

### 01 — UX Overview

High-level indicators of the user experience, including satisfaction, transaction time and abandonment.

### 02 — Frictions & parcours

Analysis of the main problems encountered, reasons for abandonment, ease of use and satisfaction according to friction points.

### 03 — Segmentation & Insights

Comparison of user experience by region, transaction type and transaction channel.
